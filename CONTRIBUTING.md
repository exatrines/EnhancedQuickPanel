# Contributing

English | [日本語](https://github.com/exatrines/exatrines/blob/main/docs/CONTRIBUTING.ja.md)

Contributions are always welcome! Bug reports, suggestions, documentation improvements, and pull requests all help make these projects better.

## Submitting a Contribution

Whether or not you use AI, please:

- **Explain why the change is necessary in your own words.**
- Understand and review your changes, and verify them thoroughly.
- Follow the target project's license and contribution guidelines.

For bug reports, describe the problem, the expected behavior, and how to reproduce it. Include relevant version information and logs when available, and remove personal information or secrets before sharing them.

For pull requests, explain what changed and why, describe how you verified it, and mention any known limitations or checks you could not perform. Keep the changes focused so they can be easily reviewed. Follow the repository's existing structure and style.

If you're planning a large change, please get in touch before submitting a pull request so we can discuss the approach and work on it together!

## AI-Assisted Contributions

AI assistance is welcome under the same expectations as any other contribution. Submit only changes you can understand, review, and take responsibility for. AI-generated explanations or test results do not replace your own understanding and verification.
